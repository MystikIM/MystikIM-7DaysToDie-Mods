# NoZomZAllowed

Traders are open 24/7 and keep a 50 m safe zone around them:

- Zombies and animals that enter the zone die.
- Players inside the zone can't be hurt and can't use weapons.
- **Tools still work**: loot, break boxes and harvest inside the zone like anywhere else.

Older trader safe-zone mods disabled every item tagged `melee`, which in 7 Days to Die also covers pickaxes, axes, shovels and wrenches. This one blocks only items tagged `weapon` or `ranged`, so tools keep working.

## Install

Server-side only (XML). Drop the `NoZomZAllowed` folder into the server's `Mods` folder and restart. Players don't need it on their PC.

The vanilla trader compound itself (the walls and blocks of the trader POI) stays protected by the game engine; that part isn't controlled by this mod.

## Requirements

- 7 Days to Die V3.4 (tested on b10, with and without Project Z 3.4.2)
