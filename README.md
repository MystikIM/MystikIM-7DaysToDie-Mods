# MystikIM 7 Days To Die Mods

Original mods for 7 Days To Die, by MystikIM. One repo, one folder per mod — each has its own `ModInfo.xml` and its own `README.md` with install/customization instructions.

(Looking for the ServerKit server-management panel? That's a separate fork of someone else's project, kept in its own repo: [MystikIM-ServerKit-V3.1](https://github.com/MystikIM/MystikIM-ServerKit-V3.1) — not mixed in here, since everything in *this* repo is my own original work.)

## Mods

| Mod | What it does |
| --- | --- |
| [`ZZZ_CATUI_ProjectZ_fit`](./ZZZ_CATUI_ProjectZ_fit) | Fits Project Z's wider UI panels into CATUI's layout, without editing either mod. Replaces the outdated official compat patch (which reintroduces a real crash). |

## Installing any mod here

Each mod folder is a complete, drop-in `Mods/<name>` folder — extract the one you want into your `7 Days to Die Dedicated Server/Mods` folder (and/or your client's `Mods` folder, for anything that's client-rendered — check that mod's own README, not every mod needs both).
